# 📄 Arabic & English Resume Evaluation System (نظام تقييم السيرة الذاتية العربية والإنجليزية)

مشروع ذكاء اصطناعي يهدف إلى تقييم السير الذاتية المكتوبة باللغتين العربية والإنجليزية من خلال تحليل محتواها واستخراج المعلومات الأساسية، ثم تقديم تقييم وملاحظات تساعد المستخدم على تحسين سيرته الذاتية وزيادة توافقها مع متطلبات الوظائف.

## 🚀 المميزات (Features)

- 📄 **تقييم السيرة الذاتية:** تحليل محتوى السيرة الذاتية وتقديم تقييم شامل.
- 🌐 **دعم اللغتين:** يدعم السير الذاتية باللغة العربية والإنجليزية.
- 🤖 **تحليل ذكي:** استخدام نموذج ذكاء اصطناعي لاستخراج المعلومات وتحليلها.
- 💡 **اقتراحات تحسين:** تقديم ملاحظات وتوصيات لتحسين جودة السيرة الذاتية.
- 📊 **عرض النتائج:** عرض التقييم والنتائج بشكل واضح وسهل الفهم.

## 🛠️ التقنيات المستخدمة (Technologies Used)

- Python
- TensorFlow / Keras
- Natural Language Processing (NLP)
- streamlit
- Git & GitHub
